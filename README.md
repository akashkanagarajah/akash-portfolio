## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akashkanagarajah/akash-portfolio.git
   cd akash-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)
